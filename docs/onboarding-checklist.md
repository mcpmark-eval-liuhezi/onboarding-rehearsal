# Onboarding Checklist — First Week

Welcome aboard! Work through this checklist during your first week:

- [ ] Day 1: Complete account setup (SSO, 2FA, Slack, email aliases)
- [ ] Day 1: Read the team handbook and code of conduct
- [ ] Day 2: Clone the main repositories and build the project locally
- [ ] Day 2: Run the full test suite and confirm it passes
- [ ] Day 3: Pair with your onboarding buddy on your first small ticket
- [ ] Day 3: Open (and merge) your first pull request
- [ ] Day 4: Meet the team — 1:1s with your manager and teammates
- [ ] Day 4: Review a teammate's pull request, even if just a nitpick
- [ ] Day 5: Deploy a change to staging with a buddy watching
- [ ] Day 5: Write down one thing that confused you and file it as an issue

**Tip:** When in doubt, ask in the team channel — no question is too small.
